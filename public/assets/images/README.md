# Bilder-Verzeichnis

Alle Bilder für die Website sind hier gespeichert.

## Dateien und ihre Verwendung:

- **hero-background.jpg** - Hintergrundbild in der Hero-Sektion (Startseite oben)
- **problem-main.jpg** - Bild in der Problem-Sektion (rechte Spalte)
- **whyus-main.jpg** - Hauptbild in der "Warum wir" Sektion
- **quickstart-step1.jpg** - Bild für Schritt 1 in der "3 Schritte zur Freiheit" Sektion
- **quickstart-step2.jpg** - Bild für Schritt 2 in der "3 Schritte zur Freiheit" Sektion
- **quickstart-step3.jpg** - Bild für Schritt 3 in der "3 Schritte zur Freiheit" Sektion

## Bilder austauschen:

1. Ersetzen Sie einfach die entsprechende .jpg Datei mit Ihrem neuen Bild
2. Behalten Sie den Dateinamen bei (z.B. `hero-background.jpg`)
3. Unterstützte Formate: .jpg, .jpeg, .png, .webp
4. Die Änderungen werden automatisch auf der Website übernommen

**Tipp:** Für optimale Performance sollten Bilder komprimiert sein:
- Hero-Background: max. 500KB empfohlen
- Andere Bilder: max. 200KB empfohlen
