# Bilder zum Austauschen

In diesem Ordner legen Sie alle Bilder ab, die auf der Website verwendet werden. **Ersetzen Sie einfach die bestehenden Dateien** durch Ihre eigenen Bilder – **der Dateiname muss gleich bleiben**.

## Welches Bild wo erscheint

| Dateiname | Verwendung |
|-----------|------------|
| **hero-background.jpg** | Hintergrundbild in der Hero-Sektion (Startseite oben) |
| **problem-main.jpg** | Bild in der Problem-Sektion (rechte Spalte mit 15h+-Badge) |
| **whyus-main.jpg** | Hauptbild in der „Warum wir“-Sektion |
| **quickstart-step1.jpg** | Bild für Schritt 1 (z. B. Digitalisieren) |
| **quickstart-step2.jpg** | Bild für Schritt 2 (z. B. Wir übernehmen) |
| **quickstart-step3.jpg** | Bild für Schritt 3 (z. B. Sie sparen) |

## So tauschen Sie ein Bild aus

1. Neues Bild in diesen Ordner legen.
2. **Gleichen Dateinamen verwenden** wie in der Tabelle (z. B. `problem-main.jpg`).
3. Alte Datei überschreiben – die Website zeigt danach automatisch das neue Bild.

Unterstützte Formate: **.jpg, .jpeg, .png, .webp**

**Hinweis:** Für schnelle Ladezeiten Bilder vorher komprimieren (Hero ca. 500 KB, andere ca. 200 KB).
